========================================
  KATYA 2.10 — HYPER-DRIVE
  Локальный ИИ-агент для Windows
========================================

ЧТО ЭТО
-------
Катя 2.10 — голосовой ИИ-агент на базе локальной модели Ollama.
Умеет управлять окнами, громкостью/яркостью, чистить ОЗУ, включать
игровой режим, качать видео через yt-dlp, ставить таймеры и заметки.
Если нужного навыка нет — сама пишет новый Python-плагин (самообучение).


БЫСТРЫЙ СТАРТ (нажал — готово)
-----------------------------
1. Установи Python 3.11+ : https://www.python.org/downloads/
   ВАЖНО: при установке отметь галочку "Add Python to PATH".

2. Дважды кликни  install.bat  (или русский  УСТАНОВИТЬ.bat).
   Он сам создаст окружение, скачает зависимости, положит ярлык
   "Katya 2.10" на рабочий стол и тут же запустит Катю. Займёт пару минут.

3. Установи Ollama : https://ollama.com/download
   После установки открой консоль и выполни один раз:
       ollama pull qwen2.5:7b

Готово. Всё остальное Катя делает сама. Дальше запускай её
через ярлык на рабочем столе (или файлом start.bat — он при
необходимости сам предложит установку).

При первом нажатии кнопки микрофона автоматически скачается
русская модель распознавания речи Vosk (~40 МБ).

----------
  - Windows 10/11

  - Ollama + модель qwen2.5:7b
