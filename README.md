# Катя — голосовой ИИ-ассистент

Приложение для Windows с голосовым общением, встроенным ИИ-ассистентом и мини-игрой.

## Скачать

Готовую сборку можно скачать в разделе **Releases** (справа) → файл **KatyaApp_windows.zip**.

## Установка

1. Скачайте и распакуйте KatyaApp_windows.zip.
2. Запустите KatyaApp.exe.
3. Если Windows покажет окно «Защита Windows SmartScreen» — нажмите **Подробнее** → **Всё равно выполнить**. Это нормально для приложения без цифровой подписи.
